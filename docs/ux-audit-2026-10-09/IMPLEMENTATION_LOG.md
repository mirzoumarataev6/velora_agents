# Визуальное ТЗ — ход реализации

Дата: 9 октября 2026. Это рабочий журнал к `VISUAL_ART_DIRECTION_BRIEF.md`, а не заявление о завершении всех 35 поверхностей.

## Сделано в текущем проходе

- Пустой старт BI: один заголовок, ясные маршруты «файл / база», брендовый signal-мотив без вымышленных данных.
- Окно подключения БД: единая зона действий без пустой нижней полосы.
- BI с данными: существующие источники идут перед повторным onboarding; список дашбордов показывает реальные сведения вместо декоративного графика; длинные подписи KPI и названия доски не обрезаются.
- Даты BI: ru/tg показывают день–месяц–год, en — ISO; невозможные даты и обратный период отклоняются до запроса, сервер продолжает получать ISO.
- Вход/регистрация: desktop-композиция продолжает визуальный язык лендинга; мобильная форма остаётся короткой.
- Создание агента: итоговый шаг резюмирует введённые настройки; подключение каналов выровнено; в пустом playground есть реальные стартовые вопросы.
- CRM: на узком экране папки выбираются компактно, показатели доступны по раскрытию, список сделок поднимается выше; в деталях сделки история раскрывается по запросу. Формы сделки и следующего шага показывают локальные даты.
- Задачи, профиль клиента и фильтры диалогов: видимый формат дат не зависит от браузерной локали; значение для сервера остаётся ISO.
- На главной панели срочный блок теперь читабелен на 320 px. Демонстрационный переключатель лендинга переведён для ru/tg/en.

## Проверено

- `composer run test`: 1952 теста, 8103 утверждения, все прошли.
- `npm run build`: успешная сборка; предупреждение Vite о крупном лениво загружаемом BI-chart чанке остаётся.
- `git diff --check`: без ошибок форматирования.
- Изолированная SQLite-демобаза: светлая/тёмная тема; 320, 390, 768, 1365 и 1920 px на выбранных маршрутах; отдельный проход с длинными таджикскими строками. Проверены клавиатурное открытие CRM-диалога, мобильный фильтр BI и разбор некорректных/корректных дат. Рабочая MySQL не использовалась.

## Ещё не закрыто по исходному Definition of Done

- Не реализован честный live-preview будущего BI-виджета на реальных данных в редакторе. Схематичную или фальшивую диаграмму вместо него не добавляли.
- Не выполнена полная матрица 35 экранов × все состояния × все темы/локали/ширины; пройдены основные маршруты и изменённые состояния.
- Контраст токенов покрыт имеющимися тестами, но отдельной проверки на реальном проекторе и с пятью участниками не было. Это требует внешней среды и людей.
- Полноценный motion-board и видеорегресс переходов ещё не сделаны; статичные скриншоты не доказывают качество анимации.
- Остальные P2-замечания к плотности списков, модальным слоям и настройкам требуют отдельного визуального прохода после согласования приоритетов.

При дальнейшем внедрении использовать тот же временный стенд `scripts/shots.sh` и `scripts/audit-ui.mjs`; не запускать тесты голым `php artisan test` из-за защиты рабочей БД.
